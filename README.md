# Матрица парных сравнений

PWA для сравнения элементов методом парных сравнений: «лучше / равно / хуже», опрос обеих сторон пары, поиск противоречий (прямых, строгих и нестрогих циклов), коэффициент согласованности Кендалла, рейтинг и веса, сохранение проекта в файл и экспорт в PDF. Работает офлайн; данные хранятся только на устройстве.

Спецификация: `docs/spec.md`.

## Запуск на ноутбуке (openSUSE Tumbleweed)

```bash
sudo zypper install nodejs-default npm-default   # если Node.js ещё не установлен
cd pairwise
npm install
npm run dev        # режим разработки: http://localhost:5173
```

Другие команды: `npm test` (тесты), `npm run lint`, `npm run build` (сборка в `dist/`), `npm run preview` (просмотр сборки с офлайн-режимом: http://localhost:4173).

## Публикация на GitHub Pages

1. Создайте на GitHub публичный репозиторий, например `pairwise`.
2. В папке проекта:
   ```bash
   git remote add origin https://github.com/<логин>/pairwise.git
   git push -u origin main
   ```
3. В репозитории: Settings → Pages → Source: **GitHub Actions**.
4. После сборки (вкладка Actions) приложение доступно по адресу `https://<логин>.github.io/pairwise/`.

## Установка как приложение

- **Android (Chrome, Samsung Internet, Firefox):** откройте адрес, меню → «Установить приложение» / «Добавить на главный экран».
- **Windows (Chrome, Edge):** значок установки в адресной строке. Firefox на Windows — с версии 143.
- **Linux (Chrome/Chromium):** значок установки в адресной строке. В Firefox на Linux установка не поддерживается, но приложение работает во вкладке и офлайн.

## Данные

Проекты хранятся в браузере (IndexedDB) на каждом устройстве отдельно. Перенос и резервная копия — через «Сохранить файл проекта» (`.pairwise.json`) и «Открыть файл проекта». Очистка данных браузера удаляет проекты, поэтому приложение напоминает сохранить файл.

## Структура

- `src/core/` — расчёты (чистые функции, покрыты тестами)
- `src/storage/` — IndexedDB и файл проекта
- `src/pdf/` — экспорт в PDF
- `src/ui/` — экраны
