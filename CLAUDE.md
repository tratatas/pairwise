# Матрица парных сравнений

PWA для сравнения элементов методом парных сравнений («лучше / равно / хуже»). Полная спецификация: `docs/spec.md`. Читай её перед каждой задачей; при расхождении спецификация главнее этого файла.

## Стек

TypeScript (strict), React, Vite, vite-plugin-pwa, IndexedDB через `idb`, jsPDF + jspdf-autotable, Vitest. Размещение: GitHub Pages через GitHub Actions.

## Структура

- `src/core/` — чистые функции расчётов без React и браузерных API: пары, счётчик, порядок, матрица, очки, противоречия, циклы, ζ.
- `src/storage/` — IndexedDB, сохранение и импорт файла проекта.
- `src/pdf/` — экспорт в PDF.
- `src/ui/` — экраны и компоненты.
- `docs/spec.md` — спецификация.

## Правила

- Интерфейс только на русском. Идентификаторы и комментарии в коде на английском.
- Расчёты только в `src/core/`, каждая функция покрыта тестами; эталонные значения из раздела 7 спецификации.
- Только API, работающие в Chrome, Edge, Firefox (Windows, Linux, Android) и Samsung Internet. Не использовать File System Access API.
- Никаких сетевых запросов с данными пользователя: данные хранятся только на устройстве.
- Сначала телефон: интерфейс должен работать от ширины 360 px.
- Не добавлять функции вне текущей задачи; новые идеи записывать в `docs/backlog.md`.
- Перед завершением задачи: `npm run lint`, `npm test`, `npm run build` без ошибок.

## Команды

- `npm run dev` — разработка
- `npm test` — тесты
- `npm run lint` — проверка кода
- `npm run build` — сборка
- `npm run preview` — просмотр сборки
